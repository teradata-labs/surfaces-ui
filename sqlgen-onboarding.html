👋 Welcome to the SQL Gen Onboarding Console.

Fill in your connection details in the left panel, then navigate through the sections to onboard your environment.

Recommended flow:
1. Set credentials (left panel)
2. Health Check → Connect (Session)
3. Create VectorStore → Wait for READY
4. Disconnect session
5. Upload Table & Column Descriptions
6. Run Index Scripts → Monitor Status
7. Upload metadata files (optional)
8. Initialize SQL Gen
