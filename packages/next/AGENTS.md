# `packages/next`

Agent notes for this folder. The rules that hold everywhere are in the root [AGENTS.md](../../AGENTS.md). What you learn about this folder goes here.

| Path | What it is |
|---|---|
| `packages/next` | Next.js (15 or later, App Router; `next` is a peer). Serves site-catalog pages as the routes of an app: `siteParams(site, values)` for `generateStaticParams` on an optional catch-all (`app/[[...route]]`, `[]` for the home page; a route that takes values with none given is an error), `siteMetadata(site, params, { resolveImage, describe })` for `generateMetadata` (title with the site's after it, description, canonical path, link preview), and `SitePage`, a server component: it matches the address (`matchRoute`, a fixed route before one with a value; `notFound()` otherwise), refuses a page its catalog refuses, merges the app's `data` and the route's values (at `/@route`) into the page's data and resolves image names on the server (`preparePage`), so only plain JSON reaches the browser, and draws it with `SiteSurface` (`@surfaces-ui/next/client`, `"use client"`), which renders to HTML on the server, hydrates with no mismatch, and sends a click on a link to a path on the site through Next.js's router. `SurfaceSection` (a server component) draws one page document as a part of a page the app writes itself, any number on one page, each themed in its own region: `data`, `theme`, `resolveImage`, `imageOrigins`; `prepareDocument` and `assertPage` are what it and `SitePage` share. The site is `SiteRoutes` (`title`, `theme`, `pages` of `route`, `page`, `meta`), the routes part of the planned site document. Run with a real `next build` (16.4, Turbopack, static export; `apps/recipes/src/nextjs-site`, when `SURFACES_TEST_NEXT` is set, which CI's `nextjs` job does on every push and pull request) and the export opened in Chromium (the routes and a page of the app's own with a section in it). Not built: layouts, catch-all site routes, an app's own catalog through `SitePage` (`SiteSurface` takes `catalog` and `renderers` from a client file), the Pages Router. |
