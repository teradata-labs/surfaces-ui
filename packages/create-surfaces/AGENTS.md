# `packages/create-surfaces`

Agent notes for this folder. The rules that hold everywhere are in the root [AGENTS.md](../../AGENTS.md). What you learn about this folder goes here.

| Path | What it is |
|---|---|
| `packages/create-surfaces` | `npx create-surfaces <dir>`: writes a Vite app (a dashboard `PageDocument`, a chat over `connectAgent`) and a `surfaces.config.ts` (seeds, `anthropicAgent` when `ANTHROPIC_API_KEY` is set). It installs the released packages from npm; `--from-repo <checkout>` packs a checkout's packages into `vendor/` instead, to try changes that are not released yet. |
