# `packages/components/src/table`

Agent notes for this folder. The rules that hold everywhere are in the root [AGENTS.md](../../../../AGENTS.md), and the rules every component follows are in [packages/components/AGENTS.md](../../AGENTS.md). What you learn about this folder goes here.

| Component | Use it for | Key props |
|---|---|---|
| `DataTable` | The rows an app holds (people, invitations, jobs, keys) as a table: headings that ask the host to sort (`aria-sort` on the heading), check boxes for the rows and the whole page, each row's everyday actions as `ItemControls` and a menu on a right click (`useContextMenu`); columns marked `medium` or `wide` give way as the table's own width narrows (`@container sf-table`). It sorts, filters and pages nothing itself: the host asks its server and hands over one page. For the rows of a query use `DataGrid` | `label`, `columns` (`id`, `label`, `cell`, `sortable`, `align`, `show`), `rows`, `rowKey`, `rowName`, `rowHeader`, `sort`, `onSortChange`, `selected`, `onSelectedChange`, `selectable`, `allSelected`, `rowControls`, `controlsShow`, `rowMenu`, `rowState`, `loading`, `empty` |
| `SelectionBar` | What to do with the rows chosen in a `DataTable`: the count (announced), the actions with one that takes away moved last, Clear, and, once the page is ticked and more match, "Select all N that match" so an action reaches rows on pages never opened; a form an action opens goes below it. Runs nothing itself | `count`, `actions` (`id`, `label`, `onSelect`, `danger`, `disabled`, `expanded`), `onClear`, `label`, `pageSelected`, `total`, `allMatching`, `onAllMatchingChange`, `busy`, `children` |
| `Pagination` | "51–100 of 126" (announced) with Previous and Next, for a list the host pages on its server; draws nothing when one page holds every row | `offset`, `pageSize`, `total`, `onChange`, `label`, `busy` |

## Rules

- **The rows an app holds are a `DataTable`, never a table drawn by hand.** A list of people, invitations, jobs or keys that a host fetches from its own server is a `DataTable`, with `SelectionBar` for what to do with the rows chosen and `Pagination` beneath. The table sorts, filters and pages nothing (rule 2 holds for an app's rows too): a heading asks with `onSortChange`, and the host asks its server and hands over the page. "Select all that match" means the host acts on its search and filters, never on keys it does not have. Ask first for anything hard to undo with `useConfirm` (never the browser's `confirm()`), name the button for the action, and report what happened, with whom it left alone and why, in an `ActionReceipt` (`partial` when some were skipped). A status beside a row is a `StatusBadge`; a field that suggests as a person types is a `Combobox`. The rows of a query stay a `DataGrid`.
