# Release v0.1.0 - 2026-02-27

## Summary

First production release of SurfacesUI - a reusable React component library served as pre-built HTML bundles via the Model Context Protocol (MCP). This release includes major infrastructure upgrades (Tailwind CSS 4.2.1 migration), comprehensive UI generation capabilities, and a multi-provider AI testing server.

**Release Type**: Initial Production Release
**Risk Level**: Low (new project, no breaking changes from previous versions)
**Recommended Action**: Upgrade recommended for all users

---

## 🔒 Security Fixes

**No security vulnerabilities addressed in this release** (initial release)

### Security Posture

This release includes security-focused features:

- ✅ **Input Validation**: All AI-generated specs validated against Zod schemas before rendering
- ✅ **XSS Prevention**: React's built-in XSS protection, no `dangerouslySetInnerHTML` usage
- ✅ **Sandboxed MCP Apps**: HTML bundles run in Claude Desktop's sandboxed environment
- ✅ **WCAG 2.1 AA Compliance**: All components meet accessibility standards
- ✅ **Dependency Scanning**: Automated Dependabot security updates enabled

---

## ⚠️ Breaking Changes

**None** (initial release)

### URI Scheme Change (Non-Breaking)

Changed internal URI scheme from `surfaces-ui://apps/` to path-based `surfaces-ui/apps/` for better MCP client compatibility. This is handled transparently by the server - no user action required.

## ✨ New Features

### 1. Tailwind CSS 4.2.1 Migration

- Migrated from Tailwind CSS 3.x to 4.2.1 with full design system preservation
- Switched from PostCSS to `@tailwindcss/vite` plugin per v4 upgrade guide
- Applied official Tailwind v4 upgrade tool transformations
- Fixed universal CSS reset that was breaking spacing utilities
- Implemented FOUC (Flash of Unstyled Content) prevention
- Created comprehensive spacing showcase with reusable `ThemeWrapper` component

**Benefits**: Better performance, smaller bundle sizes, improved developer experience

### 2. JSON Render App - UI Generation from Natural Language

Complete overhaul of the json-render app with production-ready AI UI generation:

#### Sample Data & Column Validation
- Sample data generator updated with AI-compatible columns: `id`, `name`, `product`, `category`, `value`, `amount`, `region`, `status`, `date`
- Registry components (`CatalogTableWithFilters`, `CatalogChartWithControls`) now validate spec columns against actual data
- Automatic fallback to derived columns when AI generates invalid column names
- Debug logging for empty data scenarios

#### Theme System
- System/light/dark theme toggle with persistence via localStorage
- Proper theme inheritance across all components
- Standalone mode detection with user-friendly warnings

#### Layout Improvements
- New horizontal layout with side-by-side prompt/results view (70/30 split)
- Raw JSON specification viewer alongside rendered components
- Improved example prompts UI with better discoverability
- Clear visual feedback during generation with progress indicators

#### Validation Improvements
- Fixed `SQLResultsDisplay` context prop validation (must be "web" or "mcp-apps")
- Auto-fix logic for common AI generation mistakes
- Comprehensive error messages with retry capabilities

### 3. Multi-Provider AI Server

New `ai-api-server.mjs` supporting multiple LLM providers for local testing:

#### Supported Providers
- **AWS Bedrock** (Claude via Bedrock)
- **Anthropic API** (Direct Claude API)
- **OpenAI API** (GPT-4o)
- **Google Gemini API**

#### Features
- Streaming JSONL responses with real-time UI updates
- Automatic spec validation and error correction
- Column name validation and auto-fix
- Environment-based provider configuration
- Comprehensive system prompt with available columns and components

#### Configuration
```bash
# .env file
AI_PROVIDER=bedrock  # or anthropic, openai, gemini
AWS_REGION=us-east-1
# Provider-specific API keys as needed
```

### 4. Component Library Enhancements

- Added 5 new primitive components with consistent API
- Added 4 molecule-level components (TableWithFilters, ChartWithControls, etc.)
- Kitchen sink app reconciliation with improved organization
- Success and warning color tokens added to Tailwind preset
- Persistent theme switcher across showcase and kitchen sink apps

### 5. Demo Navigation & Organization

- Renamed "test apps" to "demos" for clarity
- Global demo navigation across all showcase applications
- Improved app structure with better categorization
- MCP Apps integration with Claude Desktop

### 6. Documentation

- Comprehensive MCP testing results (`MCP_TESTING.md`)
- Release notes following OpenSSF best practices (this document)
- Updated README with current architecture and usage
- Improved roadmap formatting with phase breakdown

```

├── packages/
│   ├── components/       # React component library + HTML apps
│   ├── mcp-adapter/      # Framework-agnostic MCP resource adapter
│   └── server/           # Standalone Node.js MCP server
```

## 🚀 Installation & Upgrade

### New Installation

```bash
# Clone repository
git clone https://github.com/teradata-labs/surfaces-ui.git
cd surfaces-ui

# Install dependencies
pnpm install

# Build all packages
pnpm build

# Build HTML apps
pnpm build:apps

# Run MCP server
pnpm --filter @surfacesui/server start
```

### Claude Desktop Configuration

Add to `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "surfaces-ui": {
      "command": "npx",
      "args": ["@surfacesui/server"]
    }
  }
}
```

### AI Testing Server (Development)

```bash
# Configure provider in .env
echo "AI_PROVIDER=bedrock" > .env

# Start server
node ai-api-server.mjs

# Access at http://localhost:3457/json-render
```
