# App components

Components an app places itself, beside the catalog's, which an agent draws ([docs/catalog](../catalog/README.md)). Each page lists the props that are plain data, the parts a host supplies in code, its callbacks and an example. The playground's Components area draws each live under App components.

Generated by `pnpm docs:gen` from `appComponents.ts` in `packages/chat`, `packages/components` and `packages/devtools`. Do not edit by hand.

- [AnalyticsChat](AnalyticsChat.md) (`@surfaces-ui/chat`): The chat for data people: the conversation always shown, with a rail of panels beside it for only what the host gives: saved conversations (`sessions`), tables and files to attach (`browse`), and the agent's setup (`agents` or `providers`).
- [Chat](Chat.md) (`@surfaces-ui/chat`): A conversation with any agent, on its own: replies hold Markdown, tool steps, approvals and any catalog component drawn inline.
- [PageStudio](PageStudio.md) (`@surfaces-ui/chat`): A page beside an instruction box: a person says what to change, an agent answers with A2UI, and its reply becomes page edits checked against the catalog.
- [ThemePicker](ThemePicker.md) (`@surfaces-ui/components`): Lets a person choose how everything looks: a preset, light or dark, the accent, chart colours, corner radius, font and density.
- [ConnectionBuilder](ConnectionBuilder.md) (`@surfaces-ui/components`): Sets up Parquet, Delta or Iceberg data on S3, GCS, Azure, https or disk, and writes the configuration for the server with the names of the environment variables to set.
- [ModelLineage](ModelLineage.md) (`@surfaces-ui/components`): Where a semantic model's rows come from when a pipeline builds them: the dataset, when it was last built, the latest run's checks, whether its key was checked and what it reads.
- [ChecksPanel](ChecksPanel.md) (`@surfaces-ui/components`): A dataset's checks (unique, not null, relationships, accepted values, row count) with their latest results, failures first.
- [ObjectInfo](ObjectInfo.md) (`@surfaces-ui/components`): What the backend knows about a database, schema or table: its kind, format, size, columns and keys.
- [CertificationBadge](CertificationBadge.md) (`@surfaces-ui/components`): Marks certified or deprecated data wherever an object is shown, with a symbol and words as well as colour.
- [ItemControls](ItemControls.md) (`@surfaces-ui/components`): The controls of one item (a tile, a framed component) as a row of icons: quiet until the item is pointed at or focused, each named at once in a tooltip, one tab stop with arrows between them.
- [ResizeHandle](ResizeHandle.md) (`@surfaces-ui/components`): A handle on the right or bottom edge of something, dragged to change its width or height: the same handle Arrange draws between a Grid's columns and under a component, for an app to place between two panes of its own.
- [SegmentedControl](SegmentedControl.md) (`@surfaces-ui/components`): A few equal choices of which exactly one holds, as one bar: build or view, chart or table, light or dark.
- [DataTable](DataTable.md) (`@surfaces-ui/components`): The rows an app holds, as a table: people, invitations, jobs, keys.
- [SelectionBar](SelectionBar.md) (`@surfaces-ui/components`): What to do with the rows a person chose in a `DataTable`: how many, the actions, and Clear.
- [Pagination](Pagination.md) (`@surfaces-ui/components`): Which rows are shown, "51–100 of 126", with Previous and Next, under a `DataTable` a host pages on its server.
- [ConfirmDialog](ConfirmDialog.md) (`@surfaces-ui/components`): Asks a person to confirm one action before it runs, as a modal dialog: the page behind cannot be used, focus starts inside (on Cancel for something that takes away) and returns where it was, and Escape or a press outside cancels.
- [StatusBadge](StatusBadge.md) (`@surfaces-ui/components`): A short status beside the thing it describes: an account on or turned off, a job running or failed, an invitation waiting.
- [Combobox](Combobox.md) (`@surfaces-ui/components`): A text box that suggests as a person types: a person to hand work to, a table, a tag.
- [Popover](Popover.md) (`@surfaces-ui/components`): A button that opens a small panel of controls beneath it: a view's width, zoom and data state behind one View button on a crowded toolbar.
- [NavBar](NavBar.md) (`@surfaces-ui/components`): Navigation across the top of a site, after Apple's: the sections on a glass bar that stays at the top, and beneath it the current section's name and its pages.
- [SurfacesDevTools](SurfacesDevTools.md) (`@surfaces-ui/devtools`): Developer tools for agent-generated UI.
