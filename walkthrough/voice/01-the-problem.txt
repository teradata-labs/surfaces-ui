Every data team ends up building the same things. A grid that can handle millions of rows. Charts that don't lie. A catalog page, a relationship diagram, a pipeline view. And now there's a new user of all of it: an agent, which needs to draw that same UI in a chat, a side panel, or inside Claude Desktop. Surfaces UI is a React library for exactly that. Let me show you around. Everything here runs on one sample dataset, and when I switch it, every page follows.
