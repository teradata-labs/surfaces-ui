   [data-density="spacious"] {

3. Define base spacing tokens and scaled variants:
   ```css
   :root {
     /* Base spacing (unscaled) */
     --space-xs: 4px;
     --space-sm: 8px;
     --space-md: 16px;
     --space-lg: 24px;
     --space-xl: 32px;

     /* Scaled spacing (for density-aware components) */
     --space-xs-scaled: calc(var(--space-xs) * var(--density-scale));
     --space-sm-scaled: calc(var(--space-sm) * var(--density-scale));
     --space-md-scaled: calc(var(--space-md) * var(--density-scale));
     --space-lg-scaled: calc(var(--space-lg) * var(--density-scale));
     --space-xl-scaled: calc(var(--space-xl) * var(--density-scale));

     /* Typography scaling (conservative - don't go below 14px for WCAG) */
     --font-size-sm: 14px;
     --font-size-md: 16px;
     --font-size-lg: 18px;

     /* Line heights (fixed - don't scale to preserve readability) */
     --line-height-sm: 20px;
     --line-height-md: 24px;
     --line-height-lg: 28px;

     /* Fixed sizes (never scale) */
     --border-width: 1px;
     --icon-size-sm: 16px;
     --icon-size-md: 20px;
     --icon-size-lg: 24px;
   }
   ```

Important: Typography and borders remain FIXED per research (Pitfall 2: Density Scaling Breaking Fixed Sizes). Only spacing scales with density.

**Part B: Add FOUC prevention script to index.html**

Find the index.html file and add inline script BEFORE the app renders (in `<head>` or very early in `<body>`):

```html
<script>
  // Prevent flash of wrong theme - run before render
  (function() {
    const theme = localStorage.getItem('theme') || 'system';
    const isDark = theme === 'dark' ||
      (theme === 'system' && window.matchMedia('(prefers-color-scheme: dark)').matches);
    if (isDark) {
      document.documentElement.classList.add('dark');
    }
    // Also restore density preference
    const density = localStorage.getItem('density') || 'comfortable';
    document.documentElement.setAttribute('data-density', density);
  })();
</script>
```

This script:
1. Reads theme preference from localStorage
2. Respects system preference when set to 'system'
3. Applies 'dark' class before first paint
4. Restores density attribute from localStorage
