  <action>
Measure the json-render-cdn.html bundle size in both raw and gzipped formats:

**Measure raw size:**
```bash
ls -lh packages/components/dist/apps/json-render-cdn.html
```

**Measure gzipped size:**
```bash
gzip -c packages/components/dist/apps/json-render-cdn.html | wc -c
```

**Calculate and report:**
```bash
RAW_SIZE=$(wc -c < packages/components/dist/apps/json-render-cdn.html)
GZIP_SIZE=$(gzip -c packages/components/dist/apps/json-render-cdn.html | wc -c)
GZIP_KB=$((GZIP_SIZE / 1024))

echo "Bundle Size Report:"
echo "  Raw:     $RAW_SIZE bytes"
echo "  Gzipped: $GZIP_SIZE bytes ($GZIP_KB KB)"
echo ""
if [ $GZIP_SIZE -lt 512000 ]; then
  echo "✓ PASS: Under 500KB gzipped requirement"
else
  echo "✗ FAIL: Exceeds 500KB gzipped requirement"
fi
```

**Analyze largest dependencies (manual inspection):**
Open packages/components/dist/apps/json-render-cdn.html in a text editor and search for:
- `react-dom` bundle size (look for webpack chunk comments)
- `echarts` bundle size (large visualization library)
- `@json-render` bundle size
- `lucide-react` icon library

**Expected size breakdown (approximate):**
- React + ReactDOM: ~45KB gzipped
- json-render: ~30KB gzipped
- ECharts: ~80KB gzipped (if tree-shaken correctly)
- Tailwind CSS: ~10KB gzipped (purged)
- Application code: ~20KB gzipped
- **Total estimate: ~185KB gzipped** (well under 500KB limit)

If bundle exceeds 500KB gzipped, note which dependencies are largest for potential lazy loading in future phases.
