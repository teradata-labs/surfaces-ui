**Imports (in this order):**
```typescript
import * as React from 'react';
import { createRoot } from 'react-dom/client';
import { McpAppsBridge } from '../bridge/McpAppsBridge';
import { McpBridgeProvider } from '../bridge/McpBridgeProvider';
import { ThemeProvider } from '../theme/ThemeProvider';
import { NLGenerator } from '../catalog/NLGenerator';
import { SurfacesRenderer } from '../catalog/renderer';
import '../theme/tokens.css';
```

**Bridge Setup:**
```typescript
// Create the MCP Apps bridge instance
const bridge = new McpAppsBridge();
```

**Render Logic:**
```typescript
const root = document.getElementById('root');
if (root) {
  createRoot(root).render(
    <McpBridgeProvider bridge={bridge}>
      <ThemeProvider theme="system" density="comfortable">
        <div className="p-4 max-w-4xl mx-auto">
          <h1 className="text-2xl font-bold mb-4">JSON Render UI Generator</h1>
          <NLGenerator
            baseUrl={window.location.origin}
            renderSpec={(spec) => (
              <SurfacesRenderer
                spec={spec}
                bridge={bridge}
                theme="system"
                density="comfortable"
              />
            )}
            showExamples={true}
            includeExplanation={false}
          />
        </div>
      </ThemeProvider>
    </McpBridgeProvider>
  );
}
```

**Key Decisions:**
- Use `window.location.origin` for baseUrl (allows FastMCP server on any host)
- Enable showExamples for UX discoverability
- Disable includeExplanation to reduce API cost (can be toggled later)
- Pass bridge to SurfacesRenderer for MCP action support (execute_sql, etc.)
- Use max-w-4xl container with padding for readability

**Header comment:**
```typescript
/**
 * JSON Render MCP App
 *
 * Single-file HTML bundle with natural language UI generation.
 * Works in Claude Desktop's sandboxed MCP Apps environment.
 */
```

Do NOT call bridge.connect() - McpBridgeProvider handles connection lifecycle automatically.
