  <name>Task 1: Update registry wrappers to use useStateValue hook</name>
  <files>packages/components/src/catalog/registry.tsx</files>
  <action>
Replace the incorrect data access pattern `(ctx as any).data` with json-render's `useStateValue` hook.

1. Add import: `import { useStateValue } from '@json-render/react';`

2. Update each data-dependent wrapper to use the hook:

```typescript
// BEFORE (incorrect):
function CatalogChart(ctx: ComponentContext<any, 'Chart'>) {
  const { type, xAxis, yAxis, theme, height, showDataLabels } = ctx.props as any;
  const data = (ctx as any).data || [];
  // ...
}

// AFTER (correct):
function CatalogChart(ctx: ComponentContext<any, 'Chart'>) {
  const { type, xAxis, yAxis, theme, height, showDataLabels } = ctx.props as any;
  const data = useStateValue<unknown[]>('/data') || [];
  // ...
}
```

3. Apply this fix to all 5 data-dependent wrappers:
   - CatalogChart: `useStateValue<unknown[]>('/data')`
   - CatalogDataTable: `useStateValue<unknown[]>('/data')`
   - CatalogTableWithFilters: `useStateValue<unknown[]>('/data')`

   - CatalogSQLResultsDisplay: `useStateValue<unknown>('/data')`

4. Do NOT change stateless wrappers (CatalogFilter, CatalogDensityToggle, CatalogViewModeToggle) - these already work correctly.

The state path `/data` matches the flat structure in demo-specs.ts: `state: { data: [...] }`.
